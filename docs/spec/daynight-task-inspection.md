# 任务依赖追踪与详情阅读

完整前置上下文、渐进概览、图局部依赖检查、独立详情入口和平滑路线已实现。Markdown 描述、附件导航与 bundled skill 指引已实现。本文拥有行为要求；[设计](../design/daynight-task-inspection.md)和[原型](../design/mockups/task-inspection/index.html)分别拥有机制与视觉。

## 目的与适用范围

在任务图中直接查看一个任务依赖哪些前置任务，再通过独立入口阅读完整内容。图内卡片承担依赖追踪，详情使用居中浮层。任务的 `description` 作为 Markdown 展示，公开 `using-daynight` skill 同步描述写法和实际附件链接。

图内卡片的选择规则适用于任务依赖画布。独立任务列表点击条目直接打开同一详情浮层；独立任务与任务链的分类、过滤、计数和浏览偏好沿用项目任务视图规则。

图与详情严格保留必填 `externalDependsOn`。普通依赖弱连通分量提供链成员，沿全部依赖补齐上游上下文；
箭头虚线来自关系的外部标识，卡片虚线表示链外前置。两种角色分别计算，遵守
[外部依赖需求](daynight-external-dependencies.md)，并保留检查、Details 和布局交互。

## 必须交付的行为

| 编号 | 要求 |
|---|---|
| TI1 | 完整链投影 P 保留普通分量全部成员及沿所有依赖追溯的祖先，链外前置无关后续不加入 P；链内进度/状态和项目统计仍按完整数据。P 不超过 50 个任务且 100 条依赖时全显；其余从代表任务按稳定快照顺序做后续优先、前置其次的无向 BFS，仅接纳加入后实际诱导图仍满足 50/100 的候选，只遍历接纳任务。链内与外部使用同一渐进规则。 |
| TI2 | 每卡片提供前置/后续方向控件，一次加入 P 内该方向前 20 个隐藏直接邻居，不递归，准确显示新增任务、诱导边及剩余数；手动展开无边数上限，可超过初始阈值。S 内两端均可见的全部真实依赖必须显示，无聚合卡片或捷径。两方向都无可展开邻居时不显示 footer 或分隔线，卡片为 220×96；至少一方向有控件时保留 40px 双列 footer，卡片为 220×136，空方向保留列位置。布局、边端点、视口适配、锚点居中和键盘揭示使用实际尺寸。图头部仅占一行，显示链内/外部任务数、可见/总任务数、可见/总依赖数、隐藏上游提示及全屏/收起操作；隐藏上游为零时不留占位，不显示展开或操作说明段落。操作按钮始终完整显示并固定在头部最右侧；左侧文字使用剩余宽度，溢出时单行省略截断，工具栏和页面均不产生横向滚动。窄屏全屏模式压紧语言选择器及操作按钮，保留控件的可访问名称与键盘访问。语言偏好读取或保存持续失败时，提示、重试和画布缩放/适应控件仍须互不遮挡且可操作。链外卡片、四状态、自动执行许可与阻塞标识保留，取消共享成员徽标。“收起到概览”重算并定位概览。主体、独立 Details 和方向控件均为兄弟原生按钮，各自行为由 TI3–TI5 规定。 |
| TI3 | 主体选择任务，从完整数据计算其全部上游H；只高亮当前可见祖先和它们的全部真实可见连线/箭头，按任务ID去重显示隐藏上游数。选中与前置样式不同，无关项淡化但文字/状态可辨。同卡片或画布空白清除，其他卡片替换；高亮不自动展开、不布局、不重算几何或改变视口，根无前置时仅选中自身。 |
| TI4 | 全部可见依赖平滑转弯，保留前置到后续方向、节点避让及显式外部依赖的5/4虚线语义；普通上下文边仍实线，链内外部捷径仍虚线。源右中心到目标左中心，经统一列间水平/垂直通道连接，16单位净空与≤12单位Q圆角保证平滑避让。实际body、dash pieces及原生箭头同步高亮；高亮前后S、节点位置、canonical路线、pieces和平移/缩放不变。 |
| TI5 | 主体、独立Details与方向控件均为无嵌套的兄弟原生控件。Details以链接视觉打开现有居中TaskDetailDialog；Enter/空格执行当前控件动作。Details开关与关系导航不改S或图选择，方向展开和全局reset保持显式结构/焦点行为。 |
| TI6 | 详情在浏览器可用视口居中显示，桌面最大宽度 960px、四周至少留 24px；窄屏四周至少留 12px。窗口最大高度为可用视口减去两倍边距，标题栏、详情页签和关闭入口保持可用。默认概览保留描述、PR、状态、关系及元数据并独立滚动；附件页签使用所有宽度下的左右分屏，右侧仅有一个纵向滚动所有者，行为以附件要求为准。320px 宽度下页面无整体横向溢出，表格和代码块在局部滚动。 |
| TI7 | 详情保留背景不可交互、焦点进入和约束、关闭按钮、遮罩关闭、Esc 关闭以及焦点恢复。全屏图内可打开居中详情；审批或自动执行确认窗打开时 Esc 先关闭确认窗，之后先关闭详情，再退出全屏。详情关闭后恢复到打开它的详情入口或独立任务条目；入口已消失时沿用全屏退出按钮、当前根条目、项目标题的可用回退。图刷新和卸载不遗留滚动锁或 inert 状态。该模态约束不扩展到独立附件阅读页，其普通浏览器键盘行为由附件要求拥有。 |
| TI8 | `description` 按 CommonMark 与 GFM 展示，包括标题、段落、列表、引用、表格、代码块、链接和图片。原始 HTML 作为文本展示，URL 协议处理沿用现有 Markdown 规则。空描述显示“暂无描述”；读取错误保留局部重试。API 仍保存原始字符串，CLI 和 Agent 读取原始 Markdown。 |
| TI9 | 描述中的相对附件链接及图片以当前任务附件根目录为基准；Markdown 附件内部链接仍以该文件所在目录为基准。普通左键点击不带 query/hash 的相对附件链接，激活当前详情的附件页签，使用现有附件控制器选中文件并将预览带入焦点。链接保留真实 preview URL，修饰键、非主键和上下文菜单保留浏览器行为。带 query/hash 的链接按真实 URL 导航，不承诺新增 Markdown 标题锚点功能。 |
| TI10 | 相对链接不能越过当前任务附件根。附件清单尚未完整读取时保留加载或错误状态；只有完整清单才能判定引用不存在。无效路径、文件缺失或预览失败提供可见说明及适用的重试入口。描述导航与附件区域共用同一个附件状态所有者，不发起相互独立的重复清单读取。 |
| TI11 | npm发布的using-daynight skill指导用Markdown写自足任务描述，包含具体行动、范围、交付物、约束、简明可观察完成条件及真实引用；专属主Markdown保留Solution/Acceptance criteria与完整证据。共享要求/设计/原型按当前所有权引用，不恢复problem-only或强制复制整包规则。dependsOn与PR属性语义保持，上传确认后才加实际链接，更新保留完整Markdown和有效引用。创建默认proposed，创建/执行/run-task/autopilot不隐含审批授权，明确批准才执行精确版本approve，审批不扩大实现或合并权限。 |

## 生命周期与刷新

任务创建默认为 proposed，批准、撤回审批、领取和完成使用独立版本化动作；撤回仅 todo→proposed。详情审批、自动执行许可及 session、冲突/未知结果核对和精确 int64 version 遵守[看板审批要求](daynight-web.md)；图检查不新增写请求或把 graph projection 当作审批版本。审批引起的刷新保持本文的 S、选择、视口和详情/附件状态保证，权限不因图内选择扩大。

当前渐进图保存实际 S，项目/链/页签变化或卸载后清除。方向展开重新布局、在当前缩放居中操作卡片并聚焦主体；重置重新计算概览并 framing，保留重置控件焦点。同一分量作用域的成功刷新保留实际 S 中仍属于新 P 的 ID，加代表任务后仅保留诱导无向图的对应连通部分，不自动补入新基线或新任务；刷新保留视口，失败保留旧数据、S 和视口。重置/remount 或分量/代表变化可计算新概览。

主体切换局部检查，独立 Details 沿用既有回调打开 TaskDetailDialog，详情关系切换只改变详情资源。详情打开时刷新不抢焦点，入口消失后沿用关闭时回退；概览/附件页签、分屏预览、单一附件控制器、滚动和语言状态保持既有生命周期。语言变化重译方向控件和计数，不改变 S 或增加业务请求。

依赖选择独立于详情资源和可见 S，不持久化；成功刷新从完整数据重算仍可见的选择，隐藏则清除，失败保持。H 由完整数据计算，可见成员高亮且隐藏祖先按 ID 去重计数；选择、详情打开/关闭和关系导航不展开、不布局、不移动视口。该行为与 TI3–TI5 一同验收。

## 验收与规模

独立验证 50/100 临界、稳定后续优先 BFS、只遍历接纳节点、实际诱导边预算、小链位于大项目、双向 20 项直接邻居、普通多起点唯一成员、无关外部后续排除、proposed/完成状态及无手动边上限。浏览器覆盖准确批次计数、展开锚点、重置 framing/focus、实际集合刷新连通修剪、失败保留和打开详情时不抢焦点。

API 上限为完整项目 1,000 任务/5,000 依赖。四个容量输入保持完整任务及原有 999/5,000 边，每图五次；浏览器验证有界概览、全部可见诱导边与显式展开/重置，不要求所有输入同时进入 DOM。每次保留完整有序 visibility 记录、选中任务和隐藏上游数。`openMs ≤ 3000`，选择/详情/缩放/平移反馈均 ≤300ms。普通详情→关闭→立即缩放/平移后，可信选择可见任务，再执行高亮态同序列；各项取两态较慢值，网络时间独立记录，关闭与缩放间不插入重置、适应或等待。59 项场景（原生 32、容器 27）、零重试、timeout、真实运行目标、覆盖率、超限拒绝与资源清理保持。

TI3–TI5 验收独立复算完整 H/隐藏祖先、高亮同步、兄弟选择/详情控件、选择前后几何/视口稳定及实际曲线/paint/marker。Markdown 和 skill 验收覆盖描述到附件、分页/错误/取消、窄屏/双语、原始字符串读写、实际 npm bundle 与安装夹具。原型只证明原型行为；生产验收必须绑定被测源码。
