# 任务依赖追踪与详情阅读

状态：UX-T1、UX-T3 与 [PR #134](https://github.com/codetreker/daynight/pull/134) 的渐进概览已交付。当前 [#121](https://github.com/codetreker/daynight/pull/121) 在该基线上实现 TI3–TI5 的独立依赖选择、Details 及平滑连线，当前 head 的完整验收待完成；#121 合并后才完成 UX-T2。UX-T4 Markdown 待实现。[设计](../design/daynight-task-inspection.md)、[拆分](../design/daynight-task-inspection-tasks.md)和[目标原型](../design/mockups/task-inspection/index.html)分别拥有机制、交付边界与最终视觉。

## 目的与适用范围

在任务图中直接查看一个任务依赖哪些前置任务，再通过独立入口阅读完整内容。图内卡片承担依赖追踪，详情使用居中浮层。任务的 `description` 作为 Markdown 展示，公开 `using-daynight` skill 同步描述写法和实际附件链接。

图内卡片的选择规则适用于任务依赖画布。独立任务列表点击条目直接打开同一详情浮层；独立任务与任务链的标签分类、过滤、计数和浏览偏好由其原任务负责。

## 必须交付的行为

| 编号 | 要求 |
|---|---|
| TI1 | 完整链投影 P 保留根、全部可达后续及它们的所有祖先，外部前置无关后续不加入 P；链内进度/状态和项目统计仍按完整数据。P 不超过 50 个任务且 100 条依赖时全显；其余从根按稳定快照顺序做后续优先、前置其次的无向 BFS，仅接纳加入后实际诱导图仍满足 50/100 的候选，只遍历接纳任务。链内与外部使用同一渐进规则。 |
| TI2 | 每卡片提供前置/后续方向控件，一次加入 P 内该方向前 20 个隐藏直接邻居，不递归，准确显示新增任务、诱导边及剩余数；手动展开无边数上限，可超过初始阈值。S 内两端均可见的全部真实依赖必须显示，无聚合卡片或捷径。工具栏区分完整/可见数量；外部任务、四状态、阻塞与共享标识保留。“收起到概览”重算并定位概览。方向控件是兄弟原生按钮，主体与独立详情动作由 TI3–TI5 定义。 |
| TI3 | 点击卡片主体选中该任务；H 从完整数据计算，可见 H 及其真实依赖/箭头同步高亮，按任务 ID 去重显示隐藏祖先数 |H−S|。选中与前置有不同样式，无关项淡化但文字/状态可辨。再次点击同一卡片或空白清除，另卡片替换。选择不展开、不布局、不重新计算路线或移动视口；根无依赖时仅选中自身。 |
| TI4 | 可见依赖使用平滑路线和前置到后续箭头，外部依赖保留虚线。源右侧中心到目标左侧中心经过无障碍 rank 通道，避让全部可见卡片；Q 转角对称裁切不超过 12 单位。整条线、所有实际 body pieces 和原生箭头同步高亮，选择前后节点位置、canonical d、pieces、缩放和平移不变。 |
| TI5 | 卡片主体、Details 及方向展开是无嵌套的兄弟原生控件。Enter/空格执行聚焦动作；Details 打开现有 TaskDetailDialog，不改变 S 或依赖选择，关系导航只切换详情资源。方向展开/reset 保持 PR134 的结构和焦点行为。 |
| TI6 | 详情在浏览器可用视口居中显示，桌面最大宽度 960px、四周至少留 24px；窄屏四周至少留 12px。窗口最大高度为可用视口减去两倍边距，标题栏、详情页签和关闭入口保持可用。默认概览保留描述、PR、状态、关系及元数据并独立滚动；附件页签使用所有宽度下的左右分屏，右侧仅有一个纵向滚动所有者，行为以附件要求为准。320px 宽度下页面无整体横向溢出，表格和代码块在局部滚动。 |
| TI7 | 详情保留背景不可交互、焦点进入和约束、关闭按钮、遮罩关闭、Esc 关闭以及焦点恢复。全屏图内可打开居中详情；Esc 先关闭详情，再退出全屏。详情关闭后恢复到打开它的详情入口或独立任务条目；入口已消失时沿用全屏退出按钮、当前根条目、项目标题的可用回退。图刷新和卸载不遗留滚动锁或 inert 状态。 |
| TI8 | `description` 按 CommonMark 与 GFM 展示，包括标题、段落、列表、引用、表格、代码块及链接。原始 HTML 作为文本展示，URL 协议处理沿用现有 Markdown 规则。空描述显示“暂无描述”；读取错误保留局部重试。API 仍保存原始字符串，CLI 和 Agent 读取原始 Markdown。 |
| TI9 | 描述中的相对附件链接及图片以当前任务附件根目录为基准；Markdown 附件内部链接仍以该文件所在目录为基准。普通左键点击不带 query/hash 的相对附件链接，激活当前详情的附件页签，使用现有附件控制器选中文件并将预览带入焦点。链接保留真实 preview URL，修饰键、非主键和上下文菜单保留浏览器行为。带 query/hash 的链接按真实 URL 导航，不承诺新增 Markdown 标题锚点功能。 |
| TI10 | 相对链接不能越过当前任务附件根。附件清单尚未完整读取时保留加载或错误状态；只有完整清单才能判定引用不存在。无效路径、文件缺失或预览失败提供可见说明及适用的重试入口。描述导航与附件区域共用同一个附件状态所有者，不发起相互独立的重复清单读取。 |
| TI11 | npm 中的 `using-daynight` skill 要求任务描述使用 Markdown 表达问题与真实附件链接；方案和验收继续归一个主 Markdown 附件，依赖仍只写入 `dependsOn`，PR 仍写入 `properties.pullRequests`。创建后确认上传成功再加入真实引用；执行与更新任务时保留完整 Markdown 和仍有效的引用。 |

所有新增控件、批次/隐藏数量、通知和可访问说明接入既有英语/简体中文目录；语言切换保留 S、依赖选择、视口及详情资源，不增加业务请求或改变布局输入。语言契约由[双语需求](daynight-web-i18n.md)拥有。

## 生命周期与刷新

PR134 的 S、50/100/20、精确诱导边、全局 reset 和实际 ID 刷新连通修剪保持。reset 后选择仍可见则保留，否则清除；项目/根/页签/卸载清除局部选择。成功的同身份/项目/鉴权作用域刷新按完整数据重算仍可见选择，隐藏则清除；普通失败只在同一作用域保留旧快照/S/选择/视口。既有 current-generation 401、会话/身份或项目资源转换继续执行 AuthenticatedApp 的失效和私有内容卸载规则，不为检查状态保留过期私有数据。

选择、详情打开/关闭和关系导航不改 S、几何或视口。主线 TaskDetailPanels、概览/附件页签、左右分屏和单一右滚动、同源 frame、locale 及请求生命周期保留。刷新不抢已打开对话框焦点；入口消失由关闭时回退恢复。方向 footer 消失但卡片仍可见时，在 TaskNode 的最终 DOM commit 恢复到主体并抑制视口 reveal；整卡片消失仍用图/全屏既有回退。

所有新标签、计数、状态播报和可访问说明使用既有双语目录；语言切换保留 S、H 选择、几何/视口、详情/附件资源和待完成操作，不增加业务请求。

## 验收与规模

PR134 已验收渐进渲染工作负载与 `visibility[5]` 强制回执。当前检查 PR 继承全部输入/概览/展开/reset规则并增加完整 H、精确隐藏祖先、同步节点/线/marker、兄弟控件、选择几何稳定、刷新/鉴权失效和焦点回退检查。桌面与320px、普通/全屏及两种语言均覆盖。

独立拓扑预期从 API/dependsOn 和预期 S 派生，无生产 planner/curve import；optional compilerInputs 只检验编译忠实度。实际 DOM 左右中心端口、正向水平首尾、所有Q≤12对称/相切、可见卡片避让、真实CTM、完整body coverage、解析参考弧长/虚线相位和原生RGB marker 无条件验证，缺/多边、错误箭头、穿卡片和相位/coverage负例失败。

四个完整1,000任务、999或5,000边输入各五次不变，完整API及mandatory visibility行仍校验。当前增加 `selectMs≤300`、非空selectedId和准确hiddenUpstream；open≤3000、detail/zoom/pan≤300保持。普通Details→关闭→立即zoom/pan，当前可见任务可信选择，再高亮态同序列；detail/zoom/pan取两态较慢值，network独立较大值，不插入等待/reset/fit。31场景、真实目标、零retry、timeout、coverage、超限拒绝及清理保持。PR134通过不证明当前head通过，当前源码绑定运行证据仍待完成。
