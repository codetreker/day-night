# 持久任务分组

任务的 `groupId` 表达同一个交付目标下的成员关系，`dependsOn` 表达实际前置。
分组不得随依赖变化而改变。[设计](../design/daynight-task-groups.md)拥有存储、迁移和投影机制，
[决策](../../.agents/notes/implemented/feature/2026-10-23-persistent-task-groups.md)保存被替代的根任务分组假设及取舍。

## 身份与成员

每个任务都有一个非空 UUID `groupId`。一个组的首任务是锚点，其 `id` 与 `groupId`
相同；其他成员保存同一个值。每个任务只属于一个组，组内任务可以没有依赖路径，
锚点也可以依赖组外任务。组和任务都属于同一 project；跨项目加入、指向非锚点任务或
缺失任务的分组引用必须拒绝。

没有单独的 group 资源、状态或权限。组的名称来自锚点任务标题；修改标题不修改组
身份。任务的状态与版本继续由既有生命周期拥有；组的进度和状态从完整成员集合计算。

## 创建与显式调整

| 操作 | 要求 |
|---|---|
| 创建时省略 `groupId` | 服务先生成 task ID，再以该 ID 作为新任务及新组身份。 |
| 创建时提供 `groupId` | 加入已存在的同 project 锚点任务所标识的组，不从 `dependsOn` 推断所属组。 |
| 更新时省略 `groupId` | 保留当前所属组，包括修改或清空全部依赖时。 |
| 更新时提供 `groupId` | 使用当前观察到的精确 `version`，将任务移到指定组；指定自身 task ID 时成为新组锚点。 |
| 移动已有其他成员的锚点 | 整体拒绝，保留全部字段和版本，防止其他成员失去有效锚点。 |
| 显式空值、null、错误类型或无效 UUID | 沿用严格输入校验并拒绝，不能视为省略。 |

正常元数据更新、批准、领取、完成及附件操作都保留 `groupId`。真实分组变更增加一次
任务版本和更新时间；语义空操作及过期版本遵守原有规则。授权、引用校验、锚点保护
和写入处于同一个 project 写事务。分组不改变 ready、blockedBy、环检测或状态前置要求。

CLI 的 `task create` 与 `task update` 提供 `--group-id <task-id>`，详情、列表及完整图
资源返回 `groupId`。成员调整继续使用任务更新，没有隐式整组移动或整组批准。

## Web 任务链

Web 按 `groupId` 精确划分任务；单成员组进入“独立任务”，多成员组进入“任务链”。
依赖数量与任务完成状态不改变分类。分组调整后的新完整快照统一替换分类、计数和投影。

任务链标题与创建排序取锚点任务；展开身份为持久 `groupId`。链内进度、聚合状态和
完成筛选只计算本组成员。两个页签的未完成任务数相加等于项目未完成总数，每个任务
只计一次。组外前置可以作为上下文出现在多张图中，始终不计入所展示组的进度。

完整投影包含组内全部任务与它们的完整祖先，排除无关组外后续；只绘制真实依赖。
50 任务/100 边概览和卡片方向展开保留，组内没有依赖连接的成员也必须可见或能通过
显式成员展开入口访问，不能为了可达性生成依赖边。刷新保留仍属于新投影的实际可见
任务，不因成员与锚点断开依赖连接而删除该成员。选择仍只改变高亮。

## 既有数据迁移

迁移只执行一次：沿现有依赖找出每个任务可追溯到的全部无前置根，按根的精确
`(created_at, id)` 顺序选最新者作为 `groupId`。根任务和孤立任务使用自身 ID；共享
后续只归入所选的一个组。迁移保留 task ID、状态、版本、时间、属性和全部依赖。

旧图不能确定共享后续的人类预期归属，也不能识别没有依赖连接但本应同组的任务。
确定性迁移提供可解释结果；这些历史成员需要修正时显式
更新任务 `groupId`。运行时只接受迁移完成的非空字段，不重复按依赖推导或回退。

## 验收

验证默认新组、显式加入、无连接成员、跨组前置与后续、锚点自身有前置、依赖调整
保持组身份、精确版本成员调整、占用锚点移动拒绝，以及缺失/跨项目/非锚点引用的
原子失败。完整任务与图、CLI 和 Web 必须读取同一个持久字段。

迁移覆盖分叉、共享后续、相同时间的 ID 排序、多个项目、幂等应用及元数据保持。
Web 验证组内进度、单成员分类、外部上下文、断开成员的大图展开、刷新保留、偏好、
键盘/焦点和语言切换；检查不得用依赖连通性重新定义预期成员。
