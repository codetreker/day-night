# 任务检查与依赖浏览

这个附件为交互原型提供可访问的方案链接。完整方案与任务拆分由同目录上级的任务 UI 设计文档维护。

## 依赖浏览

展开任务链时补齐全部传递上游，跨链前置作为上下文展示，不计入当前链的完成进度。点击任务卡片高亮当前任务、全部上游和沿途连线，再次点击或点击画布空白处清除。

依赖连接线使用布局产生的折线路径，对转角作半径受限的平滑处理，保留端点、直线段和箭头方向。选择只改变样式，保留节点位置、连线路径、缩放和平移。

## 居中详情

独立的详情入口打开居中浮层。描述使用 Markdown，附件链接按当前任务附件根目录解析。详情中的关系导航只替换浮层内容；关闭时恢复原详情入口焦点与原画布状态。

## 验收

- 分支、共享前置、跨链前置和已完成前置都完整参与高亮。
- 键盘能够独立选择、查看详情、访问关系和附件。
- 附件在详情浮层内预览；任务详情和全屏图按 Escape 逐层关闭。
- 320px 下正文不溢出，表格与代码块在自身区域滚动。
