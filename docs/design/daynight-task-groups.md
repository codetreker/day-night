# 持久任务分组设计

[需求](../spec/daynight-task-groups.md)拥有成员身份与可观察行为。
`groupId` 是任务的持久字段；同组关系与执行前置分别由字段及 `dependsOn` 表达。
[决策](../../.agents/notes/implemented/feature/2026-10-23-persistent-task-groups.md)保存替换原有根任务可达分组的理由。

## 服务端与事务

`tasks.group_id` 为非空 UUID，索引 `(project_id, group_id)` 支持组成员查询。
完整任务、图任务、store 投影、service 候选和 HTTP DTO 都显式携带 `groupId`；
状态动作构造完整写入值时保留该字段。没有额外 group 表或 foreign key。

创建先生成任务 UUID。字段省略时使用自身 UUID；提供时进行 UUID 正规化，在已有
project 写事务内读取同项目锚点并确认 `anchor.id == anchor.groupId`。更新从当前
任务构造候选，省略字段保持原值。移动锚点前确认没有其他成员仍引用其 ID。
显式指定自身 ID 可以建立单成员新组。服务先检查当前项目成员权限，再验证引用；
跨项目或缺失引用遵循同一拒绝语义，不扩大资源访问。

project 行锁串行化同项目的锚点检查、成员调整及创建，防止检查与写入之间产生
孤立成员。版本比较、依赖/状态验证和持久化继续处于同一事务。`groupId` 参与语义
变化比较，真正修改时只增加一次版本；生命周期转换与依赖更新没有分组副作用。

## 迁移

`009_task_groups.sql` 在既有表上增加 `group_id`。递归 CTE 从每个无前置任务沿
后续传播 `(project, root, task)`，使用去重避免多路径重复。按根的精确创建时间与
UUID 倒序选出每个任务的最新祖先根，写入组字段，再设置 NOT NULL 与索引。

这一选择优先保留较新交付目标的归属，消除共享后续的重复组内身份。DAG 的每个节点都有根，
因此合法既有数据都能取得值；异常数据应令迁移失败。旧记录的其他字段与依赖保持
原样。迁移后没有读取时修补、依赖推断或缺失值兼容。

## CLI 与公开工作流

CLI 的 task create/update 参数定义登记 `--group-id`，请求只在提供时包含该字段。
完整资源和图解码要求有效 UUID；文本与 JSON 保留真实组身份。更新复用既有精确
int64 版本路径。任务列表仅省略 description 的 JSON 投影继续保留 groupId。

`using-daynight` 的 handbook 解释字段与调整规则；create-task 区分新组和加入已确认
组。Goal 首任务创建后保留返回的 task ID/groupId，设计及每个交付任务均显式传入
该组 ID。阶段依赖只通过 dependsOn 设置，不能把“同属 Goal”转换成额外依赖。
部分登记失败时保留确认的组和任务 ID，先读回再补齐操作。

## 图索引与投影

完整图首先验证节点、组锚点、引用、状态与 readiness、统计、DAG 和规模上限。
依赖根仅用于拓扑检查；分组索引按 `groupId` 收集成员，组顺序使用锚点在服务
精确快照顺序中的位置。每个成员只归属一个组。

对组 g，`M(g) = {t | t.groupId = g}`，`P(g) = M(g) ∪ ancestors(M(g))`。
`P − M` 是组外上下文；任一端点属于组外上下文的边使用虚线。投影包含 P 的全部真实依赖边，链进度和聚合状态只遍历 M。
`|M| = 1` 的组进入独立任务列表，其余进入任务链。项目统计仍按完整唯一任务计算。

概览保留 50 任务/100 条实际诱导边预算。依赖遍历之外继续访问同组其他分量，
完整组成员通过显式批次入口展开，不生成连接它们的虚拟边。卡片前置/后续展开继续
一次最多加入 20 个隐藏直接邻居。组级成员入口保留工具栏焦点与视口，最后一批以 aria-disabled 保留入口且不再修改集合。
刷新只移除不再属于新投影的实际可见 ID，保留
有效的断开成员；重置重新计算概览。选择、详情、语言与视口生命周期沿用既有规则。

任务链展开以 groupId 标识，标题取锚点。持久字段使新增、删除前置以及跨组引用
不再改变成员身份。组外任务只作为前置上下文参与布局、高亮和阅读，不进入本组
完成计数。

## 验证

Go 侧验证迁移、引用拒绝、同项目锁、成员移动、锚点保护、版本及生命周期字段保持。
CLI 验证字段存在性、传输、严格响应与安装产物。Web 验证与依赖独立的分类和进度、
完整组外祖先、断开成员的渐进展开和刷新保留。实际浏览器使用真实服务组字段，
预期成员由 groupId 独立计算；覆盖有前置的锚点与跨组后续，不用后续可达性作为预期。
